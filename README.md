## 📖 نبذة عن المشروع (About The Project)

موقع ويب تعريفي شخصي ومعرض أعمال (Personal Profile & Portfolio) مصمم بالكامل ليدعم اللغة العربية باتجاه من اليمين إلى اليسار (**RTL**) بشكل متجاوب ومتناسق مع جميع مقاسات الشاشات (الهواتف، الأجهزة اللوحية، والشاشات الكبيرة).

تم بناء المشروع باستخدام **Bootstrap 5.3 RTL** و **Vanilla CSS** لتقديم تجربة مستخدم عصرية وسلسة.

## ✨ المميزات الرئيسية (Key Features)

- 📱 **تصميم متجاوب بالكامل (Fully Responsive):** يعمل بكفاءة على كافة أحجام الشاشات.
- 🌍 **دعم كامل للغة العربية (Native RTL Support):** اعتماد النسخة المخصصة لـ RTL من Bootstrap 5.
- 🎨 **معرض أعمال تفاعلي (Interactive Portfolio / Carousel):** صفحة مخصصة (`gallery.html`) لعرض المشاريع والخدمات.
- 🧩 **مكونات Bootstrap 5 حديثة:** استخدام الـ Grid System، النوافذ المنسدلة (Navbar Collapse)، والبطاقات (Cards).
- 🗂️ **كود نظيف ومنظم (Clean & Semantic Code):** كتابة شيفرة HTML5 دلالية قابلة للصيانة والتطوير.
